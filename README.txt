APOYO LATINO — Por una mejor calidad de vida

PUBLICAR GRATIS EN GITHUB PAGES
1. Crea un repositorio público llamado apoyo-latino en GitHub.
2. Sube directamente a la raíz los archivos index.html, styles.css, data.js, app.js y README.txt.
3. En el repositorio abre Settings > Pages.
4. En Build and deployment selecciona Deploy from a branch.
5. Elige la rama main y la carpeta /(root), y pulsa Save.
6. Espera unos minutos. La web estará en https://kreutercash.github.io/apoyo-latino/

ANTES DE DIFUNDIR
- El botón Enviar información usa un enlace genérico de Google Forms. Crea tu formulario y reemplaza el enlace en index.html por el enlace real para responder.
- data.js está vacío: añade únicamente recursos revisados y vigentes.
- La web es pública. No publiques datos personales, documentos privados, contraseñas ni información sensible.
- Revisa periódicamente teléfonos, direcciones, horarios y condiciones de cada recurso.

La plataforma es informativa y comunitaria; no sustituye asesoría legal ni profesional.
